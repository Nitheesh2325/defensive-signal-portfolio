# Support

Defensive Signal is provided as-is under the MIT License, maintained on a
best-effort basis.

## Getting help

1. Read the [README](README.md), the Guide route (`/guide/`), and the files in
   [`docs/`](docs/).
2. Search existing issues. Someone may already have asked.
3. Open a new issue using the **Question** or **Bug report** form. Include your
   Node.js version, operating system, and the exact command you ran.

## Please do not

- post real personal data, credentials, or private screenshots in issues;
- report security vulnerabilities publicly (see [`SECURITY.md`](SECURITY.md));
- ask for help deploying to a specific paid service; the starter is deliberately
  host-neutral.
